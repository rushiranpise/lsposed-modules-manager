## Fixes

- **Same-code releases:** installed updates are found when a release keeps its version code but has a newer publish time, as xviphook does.
- **Split libxposed modules:** modules whose libxposed marker is in a split APK or `native_init.list` are detected after install.
- **Update progress:** update-all progress now appears in the bottom banner used by downloads and messages, with the current module, done count, cancel and dismiss actions. The card at the top is gone.
