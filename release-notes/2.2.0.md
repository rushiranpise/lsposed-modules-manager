## Highlights

- **Developer pages:** tap **by <author>** on a module page or **More by <author>** in a card menu to see every module from that GitHub developer.
- **Cleaner cards:** outlined package pill, gold star count, gray fork count and a red favourite heart. Long descriptions expand with **Read more**.
- **More card actions:** copy the package name, open the repository's releases list or open the developer page from the three-dot menu.
- **Module page refresh:** Material 3 segmented tabs, the author below the release date, and an **Uninstall** action for installed modules.
- **AMOLED:** fully black cards, navigation pill and download banner with a hairline outline.
- **Update time:** the Modules list reports when the index was last updated on launch and after a refresh.

## Fixes

- "Open releases" opens the repository's releases list instead of a single tag.
- Empty Diagnostics storage shows `0 B` instead of "unknown size".
- The selected module tab no longer draws a checkmark.
- The Latest version label is removed from the module header.
