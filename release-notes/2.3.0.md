## Features

- **Save APKs without installing:** on Android 10 and newer, save a release APK to `Download/ModulesManager` from the module page. The transfer runs in the foreground service, shows progress in the app and notification, and can be cancelled from either place.
- **API level chips:** module cards and detail pages show the target libxposed API level. Older modules without a target API are marked **Legacy**.
- **Notification permission timing:** the permission prompt now appears when the first download, save or batch starts instead of at launch. Settings also has a Notifications entry.

## Fixes

- **Tablet navigation:** switching rail tabs from a module or developer page returns to the selected tab root instead of reopening the old detail page.
- **Background transfers:** batch downloads and manual APK saves keep running in the foreground service when the app is backgrounded.
- **Update batches:** delegated installs no longer hold up the rest of a batch, duplicate update starts are blocked, and the manager's own update is installed last.
- **Root checks:** root availability checks stop after 15 seconds instead of potentially hanging.
- **Cold start:** opening the app no longer shows a stale list-update message for cached data.
