## Features

- **Newest release across sources:** modules are checked in both their source repository and mirror, and the newest release is selected automatically.
- **Source labels:** the source picker marks the selected repository as **Current** and alternate repositories as **Fallback**.
- **Mirror sources:** mirror repositories are counted as module sources, including `Xposed-Modules-Repo` entries.

## Fixes

- **Release history:** source and mirror release histories are merged, so a newer release is not hidden when one repository is stale.
- **Build hash tags:** release tags such as `1.6.3-ceca486e` now match the installed build code.
