## Highlights

- **Uninstall works again:** modules are removed through the selected installer. Shizuku and root uninstall silently; system and session open the system uninstaller, with a fallback if the preferred one is unavailable.
- **Chinese ROMs:** Modules Manager asks once for the installed-apps permission on HyperOS, ColorOS and similar ROMs, so module detection works there.
- **Release notes:** rendered as formatted Markdown, translated with the same language and auto-translate settings as descriptions and READMEs, and separated by clean dividers.
- **Module pages:** fork count beside stars, an orange date pill, an accent author pill with the person icon, and the version pill in the metadata row. The Information tab is gone.
- **Recent and starred cards:** compact horizontal cards with equal height.
- **Sort by sources:** the Modules list can sort by how many repositories the index lists for a package.

## Fixes

- Fixed the launch crash on phones with large installed-package lists by reading package metadata one app at a time.
- Fixed a scan crash when a package disappears between the list and its metadata lookup.
- Debug modules now download the debug APK instead of the release APK with a different package name.
- Snackbars and message banners follow the app theme and match the download banner instead of appearing white.
- Tablets keep the navigation rail; phones keep the phone navigation in landscape.
